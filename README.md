# agent-bridge — the AI CLI runtime

[![ci](https://github.com/milanhorvatovic/agent-bridge/actions/workflows/ci.yml/badge.svg)](https://github.com/milanhorvatovic/agent-bridge/actions/workflows/ci.yml)

A cross-platform runtime layer that lets tools and agents drive **interactive AI CLIs** (Claude Code and Codex CLI in v1) over a structured, event-normalized JSON-RPC protocol — while the CLIs keep running as the real, subscription-billed, human-visible interactive sessions their vendors expect.

It is infrastructure, not an orchestration platform: sessions are hosted under a PTY, approvals always surface to a human (no silent auto-approval), and events — tokens, tool-call lifecycle, approval prompts with correlation IDs, lifecycle, errors — arrive as a versioned, namespaced taxonomy instead of raw terminal bytes. For CLIs that expose in-session structured channels (Claude Code's hooks and session transcript), those are the primary event sources; the terminal is host, input, interrupt, and fallback.

**Status: validation.** Written in Rust. There is no runtime yet — what exists is the CI matrix (Linux / macOS / Windows), the workspace scaffold, the platform probes (`tools/pty-probe` allocates a real PTY — ConPTY on Windows; `tools/interactive-probe` drives a real interactive CLI under one; `tools/signal-probe` proves the interrupt byte and the delivered signal are distinct mechanisms; `tools/resize-probe` proves a resize is observed as a delivered notification — repeatably, with `COLUMNS`/`LINES` pinned at their spawn-time values — and characterizes the resize-before-launch race; `tools/utf8-probe` proves multi-byte UTF-8 — ZWJ emoji, flag pairs, CJK, combining diacritics — crosses the PTY byte-exact even when reads are forced to split mid-codepoint, and that bytes which can never be UTF-8 surface as exactly-located error spans instead of silently vanishing; `tools/cleanup-probe` proves an ended session leaves nothing behind — process group / job object empty, PTY released, fd/handle counts back at baseline, no lingering ConPTY console host — both after a clean exit and after the polite-then-forced terminate escalation, with a `setsid` escapee detected as outside the group rather than pretended away), and the first slice of the conformance corpus: `crates/fake-cli`, a deterministic scripted stand-in for an interactive CLI, with three starter scenarios under `tests/corpus/fake/` whose golden event traces run against it in CI on every commit, on all three OSes. The long-streaming soak probe with its resource monitor lands next; the harness runner that compares a live runtime's events against the golden traces follows with the runtime work.
